# Anuviya Roadmap

This document outlines the features we have completed and our vision for future development.

## ✔ Completed Items
1. Core compiler pipeline (6 passes)
2. Language-neutral Intermediate Representation (IR)
3. Java language frontend (JavaParser integration)
4. Python language frontend (Tree-sitter integration)
5. Interactive dependency graph visualization
6. Real-time circular dependency detection
7. Semantic indexing of codebase elements
8. Local AI integration via Ollama
9. Executive dashboard with project health metrics
10. Workspace management & session persistence
11. Incremental analysis via ProjectWatcher
12. Quality analysis engine (hotspots, god classes)
13. Genetic algorithm-based optimization suggestions
14. Automated endpoint discovery
15. Gatling load testing integration

## 🚧 In Progress & Planned
1. Real-time collaborative analysis sessions
2. C++ language frontend implementation
3. TypeScript / JavaScript frontend
4. Advanced architectural refactoring suggestions
5. Cloud synchronization for enterprise teams (opt-in)
6. Extensible plugin marketplace
7. Intelligent code generation based on IR
8. Integration with CI/CD pipelines (GitHub Actions, Jenkins)
9. Custom query language for structural code searches
10. Enhanced reporting exports (PDF, HTML, CSV)
