# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [v0.5.0] - 2025-07-15
### Added
- Runtime Validation capabilities.
- Automated endpoint discovery.
- Authentication mechanism detection.
- Integration with Gatling for load testing.

## [v0.4.0] - 2025-06-01
### Added
- AI analysis integration via Ollama (localhost:11434).
- Architecture and scalability analysis features.
- Evidence builders for analysis reporting.
- Streaming capabilities for large codebase processing.

## [v0.3.0] - 2025-04-15
### Added
- Comprehensive Workspace management.
- `ProjectWatcher` for incremental analysis and file watching.
- Crash recovery mechanisms.
- JSON store for session persistence.

## [v0.2.0] - 2025-03-01
### Added
- Multi-language plugin architecture.
- Python language support via Tree-sitter.
- Executive dashboard for high-level metrics.
- Advanced Quality analysis engine.
- Genetic algorithm-based optimization suggestions.

## [v0.1.0] - 2025-01-15
### Added
- Initial release of the compiler pipeline (6 ordered passes).
- Language-neutral Intermediate Representation (IR).
- Java language frontend via JavaParser.
- Interactive dependency graph visualization.
- Basic entity and metric extraction.
